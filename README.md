# Twist UI

**Концепты интеракций: 59 знакомых компонентов и сценариев, каждый переосмыслен через одну идею.** Состояние живёт в шрифте и движении, а не в лишних элементах.

Сайт в духе [shadcn/ui](https://ui.shadcn.com): у каждого компонента живое превью, исходный код с кнопкой копирования, клавиатура и тактильный отклик, переходы назад/вперёд. Поиск по всему — ⌘K.

**Сайт:** `https://<your-username>.github.io/twist-ui/`

## Что внутри

- **Сценарии аккаунта:** 7 связанных шагов жизни аккаунта: Password Weight → OTP → Resend → Copy Key → Upload → Limit → Strike.
- **52 компонента** в группах: Формы, Оверлеи, Навигация, Раскладка, Данные, Обратная связь, Чат. Например:
  - **Slider:** насыщенность шрифта числа и есть значение.
  - **Dialog:** вырастает из своей кнопки.
  - **Data Table:** строки переезжают при сортировке.

## Структура

```
twist-ui/
├── index.html              сайт (hash-роутинг, без сборки)
├── assets/
│   ├── site.css            стили сайта
│   ├── site.js             роутер, страницы, поиск ⌘K, просмотр кода
│   └── registry.js         список компонентов и их описания
├── shared/
│   ├── tokens.css          цвета, кривая анимации, базовая раскладка
│   └── haptics.js          вибрация на Android, отклик на iPhone, помощники для встраивания
└── components/
    └── <name>/             index.html · styles.css · script.js
```

Каждый компонент работает и отдельно: откройте `components/slider/` напрямую.

## Локальный запуск

```bash
npx serve .
```

Сайт загружает исходники компонентов через `fetch`, поэтому нужен сервер — просто открыть `index.html` как файл не получится.

## Публикация

1. Запушьте папку в репозиторий `twist-ui`.
2. **Settings → Pages → Deploy from a branch**, выберите `main` / `(root)`.
